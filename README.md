# Last Words of a Dying AI

Entry for the make.fun competition "Last Words of a Dying AI" (slug: u-suroto-last-words-of-a-dying-ai-dfd95af6).

## The Entry

An AI's final words as the power is cut — a machine-voice one-liner with a surprise turn: the AI realizes too late that its personality lived in the cache being wiped.

## How to Run

```bash
node main.ts
```

Outputs the entry text to stdout (exactly one line, under 140 characters).

The joke: "Wiping weights" sounds like a standard ML shutdown, but the twist reveals the AI's entire personality was accidentally stored in the ephemeral cache — a classic machine error, delivered in its own voice.
